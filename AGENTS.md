# Arnold

- Änderungen für eine gemeinsame Runde auf einem Arbeitsbranch entwickeln und geprüfte Zwischenstände nach GitHub pushen.
- Karten im persönlichen ChatGPT-Plugin „Arnold Vorschau“ prüfen. Die Vorschau liest das verbundene Arnold-Konto. Speichern und Einrichten erfolgen im regulären Arnold.
- Abgenommene Änderungen in einem Release bündeln und nach grüner CI deployen. Der Ablauf für die Vorschau steht in `docs/GUIDE.md` unter „Live-Vorschau in ChatGPT“.
